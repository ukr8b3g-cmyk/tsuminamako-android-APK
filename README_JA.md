色とりどりのナマコを水槽に積み、選んだ難易度の目標まで埋めるゲームです。クリアするとナマコカードを1枚獲得します。ブラウザ版とGodot版の両方で遊べます。

## ルール

- 床に着いたナマコは残ります。
- 床より上では、別のナマコ2匹に触れると残ります。
- 触れるのが1匹以下なら、ぬるっと消えます。
- かんたん70%、ふつう80%、むずかしい90%でクリアです。

## カード報酬

20種類のカードを収録しました。N 6枚、R 6枚、SR 4枚、SSR 2枚、SECRET 2枚です。シークレットは銀色のキングナマコと、中世絵画風のクラウンナマコです。

クリア後は「お祝い → カード1枚の回転演出 → 博士の研究手帖 → 次の面へ」と進みます。ランクが高いほど演出が長く、光や粒が増えます。効果音は画面上部の「SE」で切り替えられます。獲得カードはタイトル横の「図鑑 0/20」ボタンから確認できます。重複は枚数に加算され、同ランク内では未取得カードを優先します。

10**種類**集めると称号「ナマコの仲間たち」と記念水槽の色が解放されます。取得状況はGodotでは端末の user://namako_cards.cfg、ブラウザでは同一オリジンの localStorage に保存します。排出重みと画像一覧は cards/CARD_IMPORT_GUIDE_JA.md に記載しています。

追加８枚は、ねむり・かくれんぼ・おしゃべり・いたずら・はりきり・やさしい・たんけん・おまつりという性格で描き分け、N 2枚、R 3枚、SR 2枚、SSR 1枚を割り当てました。20種類を集めると新しい全員集合カードを表示します。旧12種類をコンプリート済みの保存データも取得内容を維持し、20種類達成時に記念演出をもう一度見られます。

## 速さ

画面上部の「速さ」で自然落下と自動デモを ×1.0 / ×1.5 / ×2.0 / ×3.0 に切り替えます。マッハ（×6.0）はデモ専用です。

## 起動方法

- ブラウザ版: START.html を開きます。画像、スクリプト、音声を含む単体ファイルで、通信やログインは不要です。音声は最初の操作後に有効になります。
- Godot版: Godot 4.7.2 Standard で project.godot をインポートしてF5で起動します。追加プラグインや.NETは不要です。

分割ブラウザ版、カード素材、または小話データを編集した後は python tools/build_browser.py で browser/card_catalog.js・browser/trivia_catalog.js と単体 START.html を再生成してください。

## リジューム・全員集合・BGM更新（2026-09-30）

表示名は「つみなまこ」です。フォルダ名は既存の NamakoTsumi_v0.4 を維持しています。Godotでは旧名の保存フォルダにあるカード・設定・途中データを、新保存先に同名ファイルがない場合だけコピーして引き継ぎます。旧データは残します。

途中データがあるとデモに「つづきから」と「はじめから」を表示します。水槽、落下中と次のナマコ、乱数状態を保存し、復帰後は一時停止画面で待ちます。約1秒ごと、着地・クリア・一時停止・画面離脱時にも保存します。デモは途中データを上書きしません。Godotは user://namako_session.cfg、ブラウザは localStorage の namako_session_v1 を使用します。通常の設定・カード保存は引き続き保持します。ブラウザのサイトデータ削除やプライベート閲覧では永続保存できない場合があります。

クリア報酬とプレイ識別子を同じカード保存に記録し、報酬表示中に閉じても二重付与しません。20種類コンプリートで「やったね！ ナマコ全員集合」の特別カードを表示します。通常抽選の20枚とは別枠で、図鑑にも表示します。記念カードを閉じるまでは、途中復帰で演出を再表示できます。

BGMは「潮の庭」「ぽにゅぽにゅ散歩」「月の水槽」の3曲。曲名ボタンで切り替え、選曲とON/OFFを別々に保存します。追加曲は tools/build_music.py で再生成できます。マッハはデモ専用で落下を高速化し、通常プレイは最大×2.0です。カード枚数行と説明パネルの間隔を広げました。

旧12枚版の検証記録: Edgeで盤面・次ピース・乱数の保存復帰、報酬表示中の再読込による二重付与防止、12枚完了と別枠カード、BGM3曲切替とミュート維持、マッハ、390×844表示、破損保存の無視を確認。Godotの保存復帰・コンプリート試験12項目、既存報酬試験15項目、ブラウザ既存ルール22項目がPASSです。

20枚版の確認: Godot 4.7.2で報酬フロー15項目、保存復帰・コンプリート17項目がPASS。20枚のWebPと全員集合画像のGodotインポート、ブラウザ単体版への画像埋め込み一致、デバッグAPK内の21画像テクスチャ・ZIP整合性・v2/v3署名を確認しました。Godot終了時の既知のリソース残存警告は継続。ブラウザの20枚図鑑の実画面はローカルファイルを開くツール制限で未確認で、Android実機の表示・操作も未確認です。


## 水槽の空気感・柔らかな動き・図鑑拡大（2026-09-30）

背景に控えめな砂利、水草、エアの泡、ガラスの縁と上部照明を追加。夜モードは青白い水槽照明の雰囲気に変更しました。ナマコの回転には約0.28秒の柔らかな補間、着地にはつぶれと戻り、体には厚みの陰影を加えています。判定は従来のマス単位のままで、見た目に重さと柔らかさを演出します。HTML版の静的背景はキャッシュし、Godot版は本数を制限した図形で描画します。

BGMに「水槽の呼吸」を追加（全4曲）。静かな和音と疎らな音、エアストーン風のぽくぽく音を含む32秒ループです。曲名ボタンで選択できます。生成元は tools/build_aquarium_music.py です。

図鑑の獲得済みカードはクリック／タップで拡大し、拡大画像をもう一度押すと一覧へ戻ります。HTML版ではEnter／Spaceで拡大、Escapeで拡大を閉じる操作にも対応します。


## v0.4.2 難易度・研究手帖（2026-09-30）

上部の難易度ボタンで「かんたん → ふつう → むずかしい」を切り替えます。かんたんは70%目標で、現在の着地点に加えて安全に積めるおすすめ地点を金色の円で表示します。ふつうは従来の80%目標・落下速度・着地点表示です。むずかしいは90%目標、落下速度1.4倍、着地点の予告なしです。選択は保存され、途中再開でも引き継ぎます。判定の基本ルールは共通です。

クリア後はカードを獲得し、ガボジョイック・ベヘソナー博士の研究手帖に進みます。添付の `Namako_Trivia_100_v1.zip` に収録された100話を `data/namako_episodes_100.json` に組み込み、毎回ランダムに1話表示します。同じ話の連続表示は避けます。付属の出典索引は `data/SOURCES.md` とJSON内に保存しています。各話の事実関係を別途独立検証したものではありません。

「次の面へ」で新しいプレイを始めます。博士画面で閉じても同じ話から再開できます。自動デモのクリアはお祝いと研究手帖を表示します。カードの配布・表示と図鑑ボタンは通常プレイだけです。デモの研究手帖は本文の長さに応じて自動的に次へ進みます。デモが既存の途中プレイ保存を上書きすることはありません。

Godot 4.7.2で報酬・難易度・デモ経路23項目、保存再開19項目がPASS。ブラウザは100話・出典参照・連続重複回避、既存カード試験、JavaScript構文、単体HTMLへの埋め込みを確認しました。ブラウザ実画面はローカルファイルURLのツール制限で未確認、Android実機も未確認です。
