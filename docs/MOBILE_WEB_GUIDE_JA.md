# スマートフォン用HTMLと初回ガイド

## テスト用リンク

[つみなまこをブラウザーで遊ぶ](https://ukr8b3g-cmyk.github.io/tsuminamako-android-APK/)

GitHubのファイル表示はコードを見るページです。テストプレイには上のGitHub Pagesリンクを使います。

## 変更

- 初回は日本語の図解付きガイドを表示。「デモを見る」または「遊ぶ」を選ぶと閉じ、以後は同じブラウザーで初回ガイドを省略する。
- ガイドの言語ボタンと設定の日英ボタンは同じ言語設定を使用する。
- 水槽に積まれたナマコ、床に着地、2匹への接触、同色3匹が泡になる図をSVGで描く。高解像度でも文字と図がぼけにくく、画像ダウンロードを増やさない。
- ゲーム中の「ポーズ」を「メニュー」へ変更。「ゲームへ戻る」「はじめから」「デモを見る」「遊び方」を表示。
- 遊び方を読み直して戻った場合は盤面と落下中のナマコを保持。説明中は背景の進行と操作を止める。
- スマートフォンでは文字サイズを補正し、上部と操作ボタンは44 CSS px以上のタッチ領域を確保する。ブラウザーの表示領域とセーフエリアに合わせて調整する。
- 横向きでは極端に縮小せず、縦スクロールで全ての操作へアクセスできる。
- 音声を起動直後に一斉ダウンロードしないよう、再生時に読み込む。公開版は分割HTMLで、カードや音声のデータを巨大なHTMLへ埋め込まない。

## ローカル確認

Chromium/Edgeのスマートフォン・タッチエミュレーションで確認した。

- 日本語／英語 × 320×568、390×844、412×915、430×932、915×412の10条件。
- 3テーマでヘッダー・操作ボタンの44px以上の領域と説明への非重複。
- 初回表示、日英切替、説明の終了保存、デモ／プレイ選択、メニューからの再表示と盤面保持。
- 実際のタップによる左右移動・回転。既存テストでも落下・詰まり救済・同色消去・保存・図鑑・手帳を確認。
- 画像・スクリプトの読込エラー、ページ例外、未翻訳文言がないことを確認。
- 既存のブラウザー契約テスト8本、設定・表示30条件、詰まり救済6条件、同色消去12条件、日英とゼリー6条件も実行。

Android／iPhone実機、Safariの実描画、端末別の処理速度は未確認。

## 公開構成

`tools/build_web_site.py` はブラウザーに必要な81ファイルだけを `artifacts/web` へ集める。起動HTMLは約11KBで、カード画像・音声は別ファイル。APK、Godotソース、テスト、保存情報、署名鍵はWeb配布物に入らない。

`main` の更新時に `.github/workflows/pages.yml` が配布物を生成し、GitHub Pagesへ公開する。元のリポジトリの既存履歴とAPKは維持し、今回のコミットに新しいAPKは含めない。
