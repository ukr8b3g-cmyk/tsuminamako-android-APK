# v0.4.12 — 3匹の合体とナマコの表皮

## 合体ルール

- 通常サイズの3匹が上下左右でつながると、1匹の大きなナマコに合体する。色は問わない。斜めだけの接触や離れた3匹では合体しない。
- 合体後も3匹が埋めたマスをすべて保つ。達成率は減らず、穴を作ったり、既存のナマコを移動させたりしない。
- 大きなナマコ1匹でも新しいナマコを支えられる。通常サイズは従来どおり床、または別の2匹に触れると残る。
- 合体は1段階。大きなナマコ同士や、大きな1匹と小さな2匹は合体しない。3匹の色は最後に置いたナマコの色へまとまる。
- 保存の配置・カウンター・乱数を保持。保存形式はv2。通常サイズの旧v1保存も読み込める。合体済みのv2保存は旧アプリでは読めないため、アプリを旧版へ戻さない。

## 演出と見た目

- 約0.9秒で「3匹がぷるっと寄る → 1匹がポニュッと現れる → 光の輪と12個の泡・小さなきらめき」。画面全体を白くする点滅は使わない。
- 新規の `assets/audio/merge.wav` は約0.85秒の合成音。短い丸い音階が上がる。SEオフとデモの音量抑制に対応。既存の音源を上書きしない。
- 一時停止、図鑑、設定の間は合体アニメーションも停止。再開すると途中から続く。高速デモでも演出を途中で切らない。
- 「演出を軽く」では動きを抑え、短い控えめな輪で知らせる。
- ライト／ダークのナマコは濡れた光沢、濃淡、控えめなまだら、小さな丸い突起と腹側の点を追加。合体後は顔が1つになり、少し太くなる。LCDはモノクロのシルエットを保つ。
- 色、表皮、泡は既存のCanvas／CanvasItemで描画し、新たな物理エンジン・依存・画像読み込みを増やさない。合体後の1匹は最大12マス。

- 既存ルール: JS 22テスト、10,000手の不変条件、100種の計画ゲームのクリア。Godot 39テストと300手のHTML参照との一致。
- 既存の詰まり回避、イージー70%、報酬、図鑑、うんちく、保存再開も確認。
- 実機Androidのタッチ、描画速度、音量の体感は未確認。Windowsの描画確認はAndroid実機確認とは異なる。
