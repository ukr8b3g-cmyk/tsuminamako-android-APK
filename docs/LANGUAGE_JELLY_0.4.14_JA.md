## 言語

- 設定パネルの右上に「日本語 / EN」「EN / JP」のボタンを追加。
- 初回はOSの言語にかかわらず日本語。ユーザーが選んだ言語を保存し、次回も使う。
- HTMLは再読み込みせず、Godotはシーンを作り直さずに切り替える。盤面、落下中のナマコ、次のナマコ、面のID、読書履歴、獲得カードを保つ。
- ボタン、説明、現在の状態メッセージ、図鑑の名前とカード画像、博士と仲間のカード、200話の研究手帳を切り替える。日本語へ戻すことも可能。
- 設定パネルの既存の高さとプレイ領域を保つ。言語ボタンは見出しの右側に置き、既存の設定ボタンと重ならない。

## ゼリー演出

1. **0〜0.18秒:** 触れた境目が伸び、柔らかいつなぎ目が太くなる。元の3匹はまだ見える。
2. **0.18〜0.32秒:** つながった全体のシルエットへ重ねて移行する。
3. **0.32〜0.52秒:** ゼリーのように伸縮し、減衰する「ぷるん」を一瞬見せる。ナマコ本体はまだ透明にならない。泡は0.45秒から出始める。
4. **0.52〜0.9秒:** 12個の泡と輪を広げ、少し浮きながら本体を消す。

連結した姿は演出専用。盤面に大きなナマコを置き直さず、同色3匹以上が消えるルールを保つ。連結する境目と中心は演出開始時にまとめ、描画ごとの探索を減らす。設定、図鑑、一時停止中は演出も停止し、高速デモも終了を待つ。「演出を軽く」では連結・揺れを使わず0.35秒のフェード。
