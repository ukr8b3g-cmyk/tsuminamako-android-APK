# v0.4.10 デモ図鑑・速さ・ネジ配置修正

## 変更内容

- 液晶筐体のネジを四隅から均等に内側へ移動。ボタン・説明文との重なりを回避。
- デモ中の直接操作用速さボタンを復元。1倍、1.5倍、2倍、3倍、マッハを選択可能。
- 図鑑ボタンをデモ中にも表示。ゲーム中と同じ位置で、手動でカード一覧を開く。
- 図鑑閲覧中はデモの盤面進行を止め、閉じると同じ盤面で再開。閲覧によるカード追加はない。
- 日本語・英語、ライト・ダーク・液晶モード対応。

- Godot: test_demo_speed.gd で同じ24組み合わせを確認。テスト終了時のObjectDB/リソース解放警告は残る。
