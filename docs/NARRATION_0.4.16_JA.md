# 音声の安定化 — HTMLテスト版 / APK v0.4.16

## 変更

- 博士の手帳入口・博士の紹介カード・犬のコリ助・イルカのプレ号を、音声専用の1プレーヤーで再生します。
- 4本の短いWAVを事前に取得し、ページ内で再利用します。音声データ自体は変更しません。ファイル直接起動で取得できない場合は元の音声URLを使用します。
- 読み込み中と再生中はBGMを一時停止。終了・停止・失敗時は元の再生位置から復帰し、音量を180msで戻します。BGM OFF・SE OFF・バックグラウンド停止を尊重します。
- 再生Promiseの成功を確認してから再生中と表示。読み込みや一時中断の失敗は1回だけ再試行します。許可拒否の場合は自動再試行しません。
- 手帳と紹介カード拡大画面に「音声 / 停止 / もう一度 / 再試行」ボタンを追加。日英対応、スマートフォンの44pxタッチ領域を確保します。
- 閉じる・別カード・SE OFF・タブを隠す・Androidのバックグラウンド移行で、音声と保留中の再試行を取り消します。復帰時に以前の音声を自動再生しません。
- 音声の状態と直近20件の失敗情報はメモリー上の `game.audio.narration.diagnostics` に保持します。外部送信や永続保存はしません。

## 確認

Edge/Chromiumのブラウザ検証で、日英の実音声再生、4本の事前取得、聞き直し、BGM停止・復帰、OFF設定、3テーマ、320/390/430pxの縦画面と横画面を確認しました。

再生エラーを注入し、一時失敗の1回再試行、継続失敗の打ち切り、許可拒否後のタップ復旧、閉じた後のPromise無効化、バックグラウンド停止を確認しました。既存のオープニング音声・クリア音声・手帳画面も確認しています。

APKは同じHTMLコードをオフラインで同梱するAndroid System WebView版です。既存ローカルのデバッグ鍵・パッケージID `com.namakotsumi.prototype` を維持し、versionCode 16 / versionName 0.4.16とします。Androidの戻る・停止・復帰は `android-web/android_host.js` で連携します。

Android実機で今回の再生不具合が解消したかは未確認です。ブラウザでの再生成功と、端末のWebView・音声出力の確認は区別してください。

## 再ビルド

追加ライブラリなし。Python、JDK 17、既存Android SDK platform/build-tools 36を使用します。

```powershell
python tools/build_browser.py
python android-web/build.py --sdk "SDKのパス" --jdk "JDKのパス" --keystore "既存署名鍵のパス"
```

APKは作業フォルダの隣にある `builds/` に出力します。署名鍵はソースに含めません。このAPKはテスト用デバッグ署名で、Google Play提出用AABではありません。
