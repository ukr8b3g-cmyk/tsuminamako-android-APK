# つみなまこ：グラフィック刷新・軽量化仕様

作業基準: `099b6c8ce80e05411f9840c0ebb1f5eb375a2d88`

## 目的
隙間時間に遊べる小さな水槽のおもちゃ。まず画面の可読性、触った感触、3テーマの材質感を改善する。新モード・広告・課金はこの変更に含めない。

## 不変の契約
- 8×12の正方形マス、床または別の2匹のIDに接触すると固定
- 色、見た目の変形、粒子は衝突判定に影響しない
- 目標はかんたん70%、ふつう80%、むずかしい90%
- 既存カード、途中盤面、NEXT、乱数、ラウンド別の報酬重複防止を保持
- デモはプレイヤーの保存を上書きしない

## 画面
- 画面安全領域を起点に、正方形盤面と押しやすい操作列を配置
- デモタイトルを1行に収め、AUTO DEMO・NEXT・盤面の文字を重ねない
- 音、曲、テーマ、演出設定をひとつの設定画面へ集約
- 設定画面ではゲームを停止し、閉じたとき元の状態へ戻す
- 小画面、縦長、横長、日本語・英語、復帰直後を確認

## テーマと演出
- LCD: 灰緑のインク、淡い反射、くぼんだ枠、立体的な物理ボタン
- ライト: 明るい水槽、艶のあるナマコ、明確な主操作
- ダーク: 深い青、控えめな水槽照明、可読性優先
- 既存の変形演出を利用。着地と2匹への接触を短く伝え、操作を待たせない
- 演出軽減では揺れ・粒子を抑え、ルールと報酬は同じ

## 軽量化
既存カードはWebP。拡張子だけの変換を最適化とみなさない。Godot import後とAPKで比較する。人物画・金属背景・BGMを優先し、文字や顔が崩れない品質で判断する。作業用素材やテストを配布物へ混入させない。

## 検証・文書
旧テストの欠落fixtureを修復し、ルール・保存・報酬・表示・両実装の差を確認。BUILD_MANIFESTとSHA256SUMSは実在する成果物の実測値から生成し、未実行の検証をPASSと書かない。Android実機・署名済みAABの確認は別途必要。

## 追加合意
紹介文の中心は「仲間につないで、すき間を埋めよう」。HUDは積めた匹数をRemainingと誤訳せず、平均形状面積から「あと約○匹」を表示する。閾値を上げるだけでは詰まりやすいため、既存のクリア判定は維持。1080×2400と1440×3200の鮮明さを重視し、原カードは縮小しない。図鑑だけ320×480サムネイルを使用する。

BGMは元音源を作り直さず、音量の過剰な減衰を整理し、0〜100%の保存可能な音量スライダーと曲ごとの小さなRMS補正を追加する。ミュート・選曲は保持する。
