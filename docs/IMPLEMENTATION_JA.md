# 実装メモ — v0.4 カード報酬

ゲーム判定は scripts/rules.gd と browser/rules.js に分離されています。床に接地したナマコ、または別の2匹に触れたナマコが残り、80%でクリアする条件は変更していません。

## 速度

Godotの scripts/main.gd とブラウザの browser/game.js に ×1.0 / ×1.5 / ×2.0 の切替があります。自然落下と自動デモに適用し、お祝い演出やBGMの速度には適用しません。Godotは user://namako_settings.cfg、ブラウザは localStorage に保存します。

## カード

data/card_manifest.json がカードとランクの正本です。12枚のWebPを cards/images/ に配置し、報酬は有効です。N / R / SR / SSR / SECRET の重みは59 / 25 / 12 / 3 / 1で、同ランク内の未取得カードを優先します。

Godotの scripts/card_catalog.gd とブラウザの browser/cards.js が抽選、取得数、10種類達成を扱います。Godotは user://namako_cards.cfg、ブラウザは localStorage の namako_cards に保存します。

## 表示フロー

80%クリア → お祝い → カード回転と表面表示 → 結果 → もう一回。Godotの scripts/card_ui.gd とブラウザの browser/rewards.js が報酬演出と図鑑を表示します。ランク別に演出時間、色、光粒、効果音を変えています。10種類達成で称号と記念水槽の色を表示します。

browser/START.html は分割版です。tools/build_browser.py が browser/card_catalog.js と単体 START.html を生成し、単体版にはカード画像と音を埋め込みます。素材変更後は再生成が必要です。

## 検証範囲

Godot 4.7.2でImport、ヘッドレス起動、ルール試験、報酬フロー試験を実施。ブラウザ版はMicrosoft Edgeでカード表示、図鑑、保存、390×844相当の画面を確認。Android書き出しと実機確認は未実施です。


## リジューム・全員集合・BGM更新（2026-09-30）

表示名は「つみなまこ」です。フォルダ名は既存の NamakoTsumi_v0.4 を維持しています。Godotでは旧名の保存フォルダにあるカード・設定・途中データを、新保存先に同名ファイルがない場合だけコピーして引き継ぎます。旧データは残します。

途中データがあるとデモに「つづきから」と「はじめから」を表示します。水槽、落下中と次のナマコ、乱数状態を保存し、復帰後は一時停止画面で待ちます。約1秒ごと、着地・クリア・一時停止・画面離脱時にも保存します。デモは途中データを上書きしません。Godotは user://namako_session.cfg、ブラウザは localStorage の namako_session_v1 を使用します。通常の設定・カード保存は引き続き保持します。ブラウザのサイトデータ削除やプライベート閲覧では永続保存できない場合があります。

クリア報酬とプレイ識別子を同じカード保存に記録し、報酬表示中に閉じても二重付与しません。12種類コンプリートで「やったね！ ナマコ全員集合」の特別カードを表示します。通常抽選の12枚とは別枠で、図鑑にも表示します。記念カードを閉じるまでは、途中復帰で演出を再表示できます。

BGMは「潮の庭」「ぽにゅぽにゅ散歩」「月の水槽」の3曲。曲名ボタンで切り替え、選曲とON/OFFを別々に保存します。追加曲は tools/build_music.py で再生成できます。マッハはデモ専用で落下を高速化し、通常プレイは最大×2.0です。カード枚数行と説明パネルの間隔を広げました。

検証: Edgeで盤面・次ピース・乱数の保存復帰、報酬表示中の再読込による二重付与防止、12枚完了と別枠カード、BGM3曲切替とミュート維持、マッハ、390×844表示、破損保存の無視を確認。Godotの保存復帰・コンプリート試験12項目、既存報酬試験15項目、ブラウザ既存ルール22項目がPASSです。Godotの終了時リソース残存警告は継続。Godotの実画面、音の聴感、Android実機・APKは未確認です。
