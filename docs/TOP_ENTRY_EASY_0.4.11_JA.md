# v0.4.11 上部詰まり・やり直し・イージー緩和

## 仕様

- イージー: 目標85%→70%（96マス中68マス）。選択した落下倍率の75%の速さ。既存85%セーブも再開時70%へ緩和。
- ふつう90%、むずかしい95%は維持。ナマコが残る条件（床、または別の2匹に接触）は維持。
- 中央が塞がる場合は、実際に着地できる投入口と向きへ切り替える。現在の形が入らない場合は入る形へ交代。
- 上部で衝突して止まった場合は、盤面へコミットする前に投入口を再選択。画面外で消える同じ形を出し続けない。
- 横移動・回転で通れる狭い経路がある場合は、合法な入力状態を順にたどって入れる。盤面のナマコを削除したり貫通させない。
- 全形状に残れる場所がなくなった場合は「水槽がいっぱい」→「はじめから」／「デモに戻る」。詰まりはクリア・報酬の対象にしない。
- デモが詰まった場合は1.5秒待ち、新しい水槽へ進む。通常の目標達成は従来の完成演出・カード獲得へ進む。
- 日英両対応、既存の図鑑・速さボタンは維持。途中セーブの落下位置は維持。
